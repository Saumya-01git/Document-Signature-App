# SignFlow - Document Signature App

A secure MERN-based digital signature platform that enables users to upload PDF documents, place digital signatures, share signing links, and generate signed PDFs with audit trails.

## Features

* User Authentication (JWT)
* Secure PDF Uploads
* Digital Signature Placement
* PDF Signature Rendering
* Tokenized Public Signing Links
* Audit Trail Logging
* Document Status Tracking
* Responsive Dashboard

## Tech Stack

### Frontend

### Backend
